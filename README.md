# 沖繩自駕六天五夜｜靜態旅遊網站

## 檔案
- `index.html`：主網站，包含首頁、每日日程、交通、住宿、餐飲、票券與待辦。
- `weather.html`：繁體中文天氣頁，使用 Open-Meteo API；需要網路，遠期日期會提示尚無可靠預報。

## 本機預覽
直接用瀏覽器開啟 `index.html` 即可閱讀大部分內容。某些瀏覽器在 `file://` 模式可能限制天氣頁 API；部署到 GitHub Pages 後較適合測試完整功能。

## GitHub Pages 部署
1. 在 GitHub 建立一個 repository。
2. 上傳 `index.html`、`weather.html`。
3. 開啟 Settings → Pages，選擇從 `main` 分支的根目錄部署。
4. 等待 GitHub Pages 提供網址。網站以 hash 導覽，`/#days/2026-11-20` 可直接開啟指定日期。

## 日後修改
- 所有行程資料集中在 `index.html` 的 `const TRIP = {...}` 物件。
- 每日行程在 `days` 陣列；住宿在 `hotels`；票券在 `ticketIdeas`；待辦在 `todos`。
- 修改後重新上傳檔案即可。網站不會自動同步 Excel。
- 待辦勾選保存在目前瀏覽器的 localStorage；不會跨裝置同步。可在「票券與待辦」頁匯出／匯入 JSON。
- 請勿加入護照影本、訂房密碼、私人票券 QR Code 或 API 金鑰。
